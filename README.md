# Monster Dojo

A turn-based monster battling game built with plain HTML, CSS, and JavaScript.

**Play now:** https://hbck.github.io/monster-dojo/

## Features

- Progressive Web App (PWA) - works offline after first visit
- No build step required - pure HTML/CSS/JS
- Responsive design for mobile and desktop
- Monster art with fallback loading system

## Features Details

- **Turn-based combat** - Strategic monster battles
- **8 unique monsters** - Each with distinct abilities
- **Offline-first** - Full PWA support with service worker
- **No dependencies** - Pure vanilla JavaScript
