# Monster Dojo

A turn-based monster battling game built with plain HTML, CSS, and JavaScript.

**Play now:** https://hbck.github.io/monster-dojo/

## Features

- Progressive Web App (PWA) - works offline after first visit
- No build step required - pure HTML/CSS/JS
- Responsive design for mobile and desktop
- Monster art with fallback loading system
